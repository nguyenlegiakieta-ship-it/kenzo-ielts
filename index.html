Hướng Dẫn Deploy Lên GitHub Pages

Bạn muốn đưa website Kenzo Study IELTS 6.5 này hoạt động thực tế trên đường link GitHub miễn phí của bạn? Hãy làm theo 4 bước siêu đơn giản sau:

  1. 1
    Lưu file code này với đúng tên chính xác là index.html.
  2. 2
    Upload hoặc Commit file index.html này lên thư mục gốc (root) của Repository GitHub hiện tại của bạn.
  3. 3
    Vào GitHub ➔ **Settings** của Repo ➔ Menu **Pages** bên trái ➔ Phần **Source** chọn nhánh main (hoặc master) và bấm **Save**.
  4. 4
    Đợi khoảng 1 - 2 phút, GitHub sẽ cấp cho bạn đường link xuất bản có dạng: https://username.github.io/repository-name/
